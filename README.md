# Stepik Selenium Automation Course

Учебный репозиторий по курсу Stepik:
**"Автоматизация тестирования с помощью Selenium и Python"**.

Здесь собраны практические задания с курса, где отрабатываются базовые и промежуточные  
сценарии UI-автоматизации: работа с формами, чекбоксами и радиокнопками, получение  
атрибутов, выпадающие списки, скролл, загрузка файлов, алерты, переключение вкладок  
и явные ожидания.

Курс: [Stepik Selenium + Python](https://stepik.org/course/575/promo)

## Что изучено в проекте

- Поиск элементов на странице через `id`, `name`, `tag`, `css selector`.
- Ввод данных в поля (`send_keys`) и отправка форм.
- Работа с `checkbox` и `radio`.
- Чтение атрибутов элементов (`get_attribute`).
- Вычисления на основе данных из DOM и подстановка ответа в форму.
- Выбор значений в выпадающем списке.
- Прокрутка страницы через JavaScript (`execute_script`).
- Загрузка файла через `input type="file"`.
- Обработка `alert` и `confirm`.
- Переключение между окнами/вкладками браузера.
- Использование `WebDriverWait` и `expected_conditions`.

## Структура заданий

- `2_1_5 click chk_rad.py` - чекбокс, радиокнопка, заполнение формы и submit.
- `2_1_7 chest.py` - получение значения из атрибута `valuex`, решение и отправка.
- `2_2_2 class Select.py` - пример работы с классом `Select`.
- `2_2_3.py` - вычисление суммы и выбор нужной опции в `select`.
- `2_2_6 scrollview.py` - скролл до элементов и отправка формы.
- `2_2_8 load.py` - заполнение данных и загрузка файла.
- `2_3_4 submit.py` - принятие alert и дальнейшая отправка ответа.
- `2_3_6 redirect.py` - переход в новую вкладку и работа в ней.
- `2_4_8.py` - явное ожидание (`WebDriverWait`) до нужного состояния элемента.

## Стек

- Python
- Selenium WebDriver
- Google Chrome + ChromeDriver

## Как запустить

1. Установить зависимости:
  `pip install selenium`
2. Убедиться, что установлен Google Chrome и совместимый ChromeDriver.
3. Запустить любой скрипт, например:
  `python "2_4_8.py"`
